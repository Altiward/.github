# Getting help

- **Questions and ideas:** ask in
  [Discussions](https://github.com/Altiward/altiward/discussions). Please search first;
  someone may already have answered.
- **Bugs:** open an issue in the repository the bug is in, using the bug report form. For
  the server, agent and console, that is
  [Altiward/altiward](https://github.com/Altiward/altiward/issues/new/choose).
- **Setting up:** the [install guide](https://github.com/Altiward/altiward/blob/main/docs/install.md)
  covers the server, the agent, your SIEM, single sign-on, upgrades and troubleshooting.
- **Security problems:** please don't post these publicly. See the
  [security policy](https://github.com/Altiward/.github/blob/main/SECURITY.md).

Altiward is a small open-source project, so replies aren't guaranteed on any timescale.
